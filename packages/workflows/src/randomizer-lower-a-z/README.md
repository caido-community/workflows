## Author
- **Name:** [Ads Dawson, @0xmoose](https://github.com/GangGreenTemperTatum)

## Description
This workflow converts a given single character into a random character between a through z (lowercase).

## Usage
Import this workflow into Caido. It's useful during manual testing within Replay and also Automate when you want to randomize payload positions etc.
